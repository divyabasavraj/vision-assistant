## Why I chose it this way
- Next.js: one project holds both the phone web page and the `/api/ask` server function, and deploys to Vercel with one command.
- Vitest: lets me test the narration engine and the box decoder on the laptop with fake data — no phone or camera needed.
- Python venv with `uv` and Python 3.12: my Mac only has Python 3.14, and PyTorch/ultralytics are safest on 3.12. A venv keeps the training packages separate from everything else.

## What broke and how I fixed it
- `create-next-app` will not run in a folder that already has files (my `docs/`), so I scaffolded in a temp folder and copied the files in.
- Vitest 5 needs `@types/node` ≥ 22; the scaffold pinned 20. Bumped to `@types/node@^24` (I run Node 24).
