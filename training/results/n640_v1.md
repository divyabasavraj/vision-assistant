## Reading the numbers

- Overall mAP50 went from ≈0.26 to **0.667** — 2.5× — and every one of the 7 classes COCO doesn't have is now detected.
- Best: door 0.95, stairs_up 0.92, dog 0.86, bus 0.83. Worst: bicycle 0.45, pole 0.49, curb 0.50, crosswalk 0.52.
- Shared classes mostly improved (car +0.21, chair +0.56, table +0.23, person +0.11) — fine-tuning on our domain helps even for classes COCO already knew. bicycle dropped slightly (0.48 → 0.45): only 843 training boxes, often small and partially hidden.
- None of the 15 classes is below the 0.2 mAP50 alarm line from the plan, so Task 9 (v2) is about the weak four, not a rescue.
- Val mAP50 was still creeping up at epoch 50 (0.681 → 0.688 over the last 3 epochs), so the model is slightly under-trained; v2 can start from `best.pt` and run longer.

## Failure example

`failure_camels_as_dogs.jpg` — a camel herd is reported as six "dog" boxes and the person in front is missed at conf 0.35. Camel is not one of our classes, so the model picks the nearest animal it knows; the narrator would say "dog, right, near" — wrong but not dangerous. Out-of-vocabulary objects are a known limitation of a 15-class detector; the cloud Q&A tier exists for exactly this.
